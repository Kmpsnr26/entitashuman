name: backend-api-engineering
description: Backend services, REST APIs, authentication and service architecture
---

Inspect routing, middleware, schemas, auth and error conventions before editing.
Validate all untrusted input at the boundary. Apply authorization on the server, not only in UI.
Use pagination, idempotency where appropriate, structured logs, timeouts, and safe error messages.
Document request/response examples and add tests for invalid input and unauthorized access.
