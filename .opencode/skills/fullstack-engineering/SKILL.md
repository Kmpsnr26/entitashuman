---
name: fullstack-engineering
description: Plan and implement maintainable full-stack applications
---

Work from the existing architecture. Inspect package manifests, conventions, tests, and git status first.
Define API contracts and data ownership before changing both client and server.
Use typed boundaries, input validation, error handling, accessibility, and secure defaults.
Make small changes, run relevant tests, and summarize files changed plus remaining risks.
Do not overwrite user work or run destructive commands without explicit approval.
