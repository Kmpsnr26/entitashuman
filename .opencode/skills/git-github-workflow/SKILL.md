---
name: git-github-workflow
description: Safe Git operations, pull requests, reviews and release hygiene
---

Check git status, branch, remotes, and recent history before any write operation.
Never force-push, reset hard, clean untracked files, or rewrite shared history without explicit approval.
Keep commits focused. Summarize diffs, tests, risks, and migration notes in pull requests.
Do not expose tokens, private repository contents, or secrets in output.
