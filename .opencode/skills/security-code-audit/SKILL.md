---
name: security-code-audit
description: Defensive application security review and secure coding
---

Perform defensive review only. Map assets, trust boundaries, entry points, and sensitive data.
Check authentication, authorization, injection, secrets, dependency risk, logging, and data exposure.
Report findings with severity, affected file/line, impact, evidence, and a safe remediation.
Do not exploit live systems, exfiltrate data, or run destructive tests. Ask before active scanning.
